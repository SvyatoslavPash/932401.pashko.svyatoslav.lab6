# 🌡️ Конвертер температур (PWA)

Лабораторная работа №6: Введение в Node.js, Express и создание Progressive Web App (PWA).
**Вариант 16.** Тема: «Конвертер температур» (C ↔ F ↔ K).

## 📖 Описание проекта
Это полноценное веб-приложение, которое умеет конвертировать температуру между шкалами Цельсия (°C), Фаренгейта (°F) и Кельвина (K). 
Проект включает в себя сервер на Node.js/Express с REST API и клиентскую часть, работающую как устанавливаемое PWA-приложение с поддержкой офлайн-режима.

## ✨ Основные возможности
*   **Конвертация**: Перевод температур между C, F и K.
*   **REST API**: Валидация входящих данных и обработка ошибок (код 400 при неверных данных).
*   **PWA (Progressive Web App)**: Приложение можно установить на рабочий стол ПК или смартфона (благодаря `manifest.json`).
*   **Офлайн-режим**: Service Worker кеширует статику, позволяя приложению загружаться без интернета.
*   **Адаптивный интерфейс**: Простой и понятный UI.

## 🛠️ Технологии
*   **Backend**: Node.js, Express.js
*   **Frontend**: HTML5, CSS3, Vanilla JavaScript (Fetch API)
*   **PWA**: Service Worker, Web App Manifest

## 🚀 Как запустить проект

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/ваш-никнейм/temp-converter.git
   cd temp-converter
3. Установите зависимости:
   ```bash
   npm install
4. Запустите сервер:
   ```bash
   node server.js
